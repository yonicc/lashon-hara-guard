# Ollama מקומי בתוסף

## התקנה
1. בהגדרות התוסף לחצו **אשף התקנת בדיקה במחשב**. האשף זמין בעברית ובאנגלית.
2. לחצו **הורדת Ollama**, השלימו את התקנת התוכנה ופתחו אותה מרשימת התוכנות. חזרו לאשף ולחצו **התקנתי — בדיקת חיבור**. התוסף אינו יכול להתקין תוכנת מערכת בעצמו.
3. בחרו מודל ולחצו **הורדה ובדיקת ניסיון**. האשף מוריד דרך Ollama את המודל הקבוע המתאים (כ־4–5GB למודל או 8–10GB לשניהם), מציג התקדמות ומריץ בדיקה סינתטית במנוע הקיים. אין צורך בפקודות. השאירו את העמוד פתוח עד לסיום.
4. רק לאחר הצלחת הבדיקה לחצו **הפעלת המצב המקומי הזה**. ההפעלה שומרת את המצב הנבחר ומכבה במפורש fallback לענן. ללא הלחיצה ההגדרות הקיימות לא משתנות. ניתן לשנות את אפשרות הענן בהגדרות.
5. אם ההורדה נכשלת, לחצו שוב על הורדה ובדיקת ניסיון; Ollama יכולה להשתמש בחלקים שכבר הורדו. ביטול/סגירת האשף מפסיקים את בקשת ההתקנה, אך לא מוחקים קבצים שכבר נשמרו ב־Ollama. ניתוק worker מחייב פתיחה מחדש; לא נשמרת הצלחה מדומה.
6. אם מתקבלת חסימת Origin, האשף מציג עזרה גרפית ל־Windows וכפתור להעתקת כתובת התוסף המדויקת עבור `OLLAMA_ORIGINS`, ללא פתיחת שרת לרשת או היתר לכל Origin. במערכות אחרות: https://docs.ollama.com/faq .

החיבור קבוע ל־`http://127.0.0.1:11434`; אין כתובת שרת מרוחק הניתנת להגדרה. ההורדה דורשת אינטרנט דרך Ollama אך אינה שולחת תוכן הודעות. בדיקת ההתקנה משתמשת בטקסט סינתטי בלבד. אין שינוי בהרשאות התוסף לצורך האשף.
זמן inference מוגבל ל־60 שניות לכל מודל; בירור זמינות מוגבל לשתי שניות. מדידות המחקר ב־docs/40 אינן מדידה של המחשב המותקן.
הורדת מודל מוגבלת ל־30 דקות, ניתנת לביטול ומותרת רק משורת מודלים קבועה. רק `ollama-setup.html` מורשית לבקש הורדה; דפי תוכן אינם מורשים. האשף שולח heartbeat רק כל עוד העמוד פתוח כדי להשאיר את משימת MV3 פעילה. הצלחת בדיקת הניסיון מציינת תקינות חיבור והרצה בלבד, לא איכות חילוץ או פסיקה.

## גבולות החיבור
 - לולאת needs משותפת לענן ולמקומי: docs/48. במקומי הבקשות נוצרות מראשי הנתב (`mem_recent→get_recent`, `mem_search→search_history` עם ההודעה כשאילתה, `ask_user→questions`) ומשאלות הקטלוג הפתוחות של המנוע. מחלץ Ollama נשאר מחלץ צר `alias:[bool,quote]`; הוא אינו מנסח בקשות. קטעי השליפה נצרכים בסבב הבא כ־ADDITIONAL CONTEXT לא מהימן ב־render הקיים. המודל לא אומן עם הקשר; הפרוטוקול המשותף אינו הבטחת איכות חילוץ בהקשר. מזהי המודלים לא הוחלפו.
- check-mode.js נשאר מקור הניתוב היחיד. ollama-register.js רושם את שני המנועים ברקע; האשף צורך את רשימת המצבים והמנועים הקנונית ואינו משנה את memory/router או את כללי המוצר.
- raw:true, stream:false וטמפרטורה 0. ההוראה והכינויים מיוצאים ישירות מ־probe_modal.instruction ומ־contract.json; אין עותק ידני של ההוראה. תבניות Qwen ו־DictaLM מרונדרות במתאם.
- request.context עובר sanitizeContextPacket ומצורף כבלוק נתונים לא מהימנים נפרד; userNote מצורף בנפרד ומוגבל ל־500 תווים. זו הרחבה לפרומפט האימון, שאינה טענת parity או איכות של חילוץ בהקשר. ראיות מתקבלות רק מתוך הטקסט הראשי.
- החוזה המאומן מחזיר alias:[boolean, quote] ללא שדה ציון וללא הערכת משמעות. **הציון הוא ההסתברות של המודל עצמו** (0.11.4): הבקשה שולחת `logprobs:true`, ו־`scoreKeys` ב־ollama-client.js מחשב לכל מפתח min(P(הטוקן הראשון של המפתח), P(הטוקן שמכריע true/false)). הטוקנים חייבים לשחזר את התשובה בית אחר בית; אחרת, או כשאין logprobs, או למפתח כפול — אין ציון, ו־validateExtraction/factPolicy דוחים עם confidence_missing_or_invalid. הסף הקנוני (0.6) לא שונה, ואין חיתוך או המצאה של ציון.
- בכל זאת inference מופעל בפועל, התשובה מאומתת, וכללי המוצר ושאלות ההמשך מופעלים דרך runLiveRules ו־alertFor המקוריים, כולל תשובות משתמש מפורשות. פלט ריק או תקין ללא הערכת משמעות מחזיר unsure, לעולם לא none. כלל קנוני יכול להעלות ל־warn.
- זוג פסול (מפתח לא מוכר, טיפוס שגוי, ציטוט שאינו מילולי בטקסט) נשמט לבדו ומדווח ב־`invalidPairs`; שאר העובדות באותה תשובה נשמרות — כמו ב־score.py. זה מקור 84 "שורות שגיאת פורמט" בהערכת e10-v2 (81 ציטוטים לא מילוליים, 4 JSON פגום): בזמן ריצה הם נשמטו קודם את כל החילוץ. JSON פגום, פלט שאינו אובייקט, `done_reason:'length'`, timeout או כשל HTTP גורמים לכשל בדיקה. אין fallback לענן אלא אם lhgCloudFallback=true. אין הרשאת localhost נוספת: רק 127.0.0.1:11434; אין redirects או credentials.

## בנייה ובדיקות
```sh
npm --prefix engine ci
node scripts/build-ollama.mjs
node scripts/build-ollama.mjs --check
node --test extension/*.test.cjs
npm --prefix engine run typecheck
npm --prefix engine test
npm --prefix proxy ci
npm --prefix proxy run typecheck
npm --prefix proxy test
node scripts/test-ollama-browser.mjs /path/to/package-with-playwright/package.json
node scripts/test-ollama-setup-browser.mjs /path/to/package-with-playwright/package.json
```
הבנייה דורשת Python 3 (`py` ב־Windows). אין צורך ב־Modal או בחבילות Python: סקריפט הייצוא קורא AST של פונקציית ההוראה בלבד. bundle הדפדפן נבנה מהמקור ב־esbuild; evaluate משתמש ב־SHA-256 נייד מ־@noble/hashes גם ב־Node, עם אותו פלט hash. אין עריכה של engine/dist.

בדיקת Chromium טוענת את התוסף האמיתי ב־MV3, ומפעילה שרת מדומה ב־127.0.0.1:11434; היא מסרבת לרוץ אם הפורט תפוס, ואינה מחליפה שרת קיים. היא מאמתת רישום, שלושה מצבים, כללים, כשל פלט ואפס fallback. זו אינה בדיקת מודל חי.
בדיקת האשף ב־Chromium מאמתת כניסה מההגדרות, עברית/RTL, הורדה זורמת של שני מודלים, בדיקת כל מנוע, הפעלה מפורשת, חסימת 403, ניתוק אמיתי, פלט פגום, כשל הורדה, ביטול וניסיון חוזר. 176 בדיקות תוסף ושתי בדיקות Chromium עברו לאחר הוספת האשף; השרת המקומי מדומה, אין בכך אימות הורדת מודל אמיתי או איכות inference חי.

אימות בענף על בסיס origin/main: 169 בדיקות תוסף, 366 מנוע (+1 skip), 75 proxy; typecheck בשניהם ו־Chromium/MV3 עברו. בשילוב הזיכרון נבדקו גם 174 בדיקות תוסף לפני בידוד קומיט Ollama. ב־BI-1 לא נמצא executable של Ollama והפורט 11434 החזיר connection refused לפני הבדיקה המדומה; inference חי לא אומת. לא בוצע שחרור.
